## 결정 사항 (왜 이렇게 했는지)
- **요청 한도** (2026-11-08): 계정당 1200회/분(`/api/box`·방명록·차단), 전체 계정(로그인 전엔 IP)당 1500회/분.

  로그인 15분 10회·회원가입 1시간 5회·비밀번호 찾기 15분 5회는 무차별 대입 방어라 유지.
- **강화 연타**: `/upgrade` 응답에 강화 목록을 담아 화면 즉시 갱신, 상태 새로고침은 마지막 클릭 0.7초 뒤 1번
