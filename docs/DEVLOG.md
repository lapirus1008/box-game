## 나중에 점검할 것
- **비밀번호 찾기 메일 보내는 주소 = 개인 Gmail** (2026-11-10 결정)
  - 바꿀 신호: "코드 메일이 안 온다/스팸함" 문의 반복, Render Logs `[MAIL]` 실패 잦음, 개인 메일함에 유저 답장 혼재, 하루 발송이 무료 한도(300통) 근접
  - 방법: 도메인 구입 → Brevo Domains 인증 → Render `MAIL_FROM`=`noreply@도메인` (코드 수정 없음). 자세히: `docs/PLAY_STORE.md`
- **Brevo IP 차단** (2026-11-10): 처음 보는 IP(Render 서버, 미국 오하이오)에서 온 API 요청을 Brevo가 막아 첫 메일 실패.
  IP 검토를 끄는 것으로 결정(Render IP가 고정이 아님, 키 권한은 거래 메일 발송만). 메일이 다시 안 오고 Brevo에서
  "unusual IP address" 메일이 오면 같은 원인 → Settings → Security → Authorized IPs 확인
- **Brevo API 키 만료** (2026-11-10 생성 예정, 권한: Transactional email = All만)
  - 키는 설정한 기간(최대 1년, 2027-11 무렵)이 지나거나 **90일 동안 안 쓰이면 만료**됨 → 비밀번호 찾기 메일이 안 나감
  - 신호: Render Logs `[MAIL] … 메일 서비스 응답 401`, "코드 메일이 안 온다" 문의
  - 메일 관련 로그는 모두 `[MAIL]`로 시작: "메일 서비스에 넘김(id …)" = Brevo가 받음 → 안 오면 Brevo Transactional 로그·스팸함 확인,
    "가입되지 않은 이메일" / "발송 생략" = 서버가 보내지 않음, "발송 실패" = Brevo가 거절(이유가 함께 찍힘)
  - 조치: Brevo Settings → SMTP & API → API Keys에서 새 키 생성 → Render `BREVO_API_KEY` 교체. 만료 1달 전(2027-10)에 사용자에게 짚어 줄 것
- **배포 로그의 경고 2가지** (2026-11-10 점검)
  - `npm audit` 취약점 5개 → `npm audit fix`로 해결(같은 큰 버전 안 패치, 0개). 배포 로그에 다시 뜨면 같은 방법으로 패치 후 로컬 확인
  - pg `SECURITY WARNING: The SSL modes 'prefer', 'require'…`: 지금 동작엔 영향 없음(pg v8 고정).
    **pg v9로 올릴 때** Render `DATABASE_URL`의 `sslmode=require`를 `sslmode=verify-full`로 바꾸고, `db.js`의 `ssl.rejectUnauthorized:false` 정리할 것
- **Render 무료 서버**: 재시작 시 첫 접속 30~60초. 스토어 출시 시점에 Starter(월 7달러) 전환 여부를 사용자에게 다시 물을 것
- **플레이스토어 출시 진행 상황** (`docs/PLAY_STORE.md`)
  - 내부 테스트에 1(1.0.0.0) 업로드됨. 그 버전의 업로드 키와 저장소 `assetlinks.json` 지문 일치 여부는 아직 확인 안 됨
  - 앱 위 주소창이 보이면 콘솔 "앱 서명" SHA-256으로 `public/.well-known/assetlinks.json` 수정
  - 비공개 테스트 12명 × 14일 → 프로덕션 액세스 신청

## 결정 사항 (왜 이렇게 했는지)
- **요청 한도** (2026-11-08): 계정당 1200회/분(`/api/box`·방명록·차단), 전체 계정(로그인 전엔 IP)당 1500회/분.
  기준: 손가락으로 가장 빠르게(초당 20번) 1분 내내 눌러도 막히지 않을 것. 넘는 건 스크립트로 보고 `[RATE-LIMIT]` 로그로 탐지.
  로그인 15분 10회·회원가입 1시간 5회·비밀번호 찾기 15분 5회는 무차별 대입 방어라 유지.
- **강화 연타**: `/upgrade` 응답에 강화 목록을 담아 화면 즉시 갱신, 상태 새로고침은 마지막 클릭 0.7초 뒤 1번
- **'장인의 손' 스킬**은 수집가의 연구에 적용하지 않음 (연구를 공짜로 계속 올리는 구멍 방지)
- **초월** 시 도감·각성·업적은 유지, 골드·아이템·강화·연구·상자 강화·조각은 초기화. 상자 강화 +10부터 실패 시 한 단계 하락
- **광장**: 방 1~9, 정원 20명. 모두 차면 목록에서 대기. 채팅은 DB에 저장 안 함(신고된 채팅만 `user_reports`)
