전체 프로젝트 구조
box-game/                    ← GitHub 저장소 루트
├── server.js                 백엔드 진입점 (Express 앱 시작)
├── db.js                     PostgreSQL 연결 설정
├── .env                      로컬 전용 환경변수 (Git에 안 올라감)
├── .gitignore
├── routes/
│   ├── auth.js                회원가입 / 로그인 / 내 정보 조회 API
│   └── box.js                 상자 열기 / 상태 조회 API
├── game/
│   ├── config.js              게임 수치(충전, 골드, 천장 등) + 아이템 목록 + 수집가 등급
│   ├── logic.js               DB와 무관한 순수 로직 (뽑기, 천장, 숙련도, 등급 계산)
│   └── store.js               게임 데이터 DB 읽기/쓰기 함수
├── lib/
│   ├── http.js                트랜잭션 헬퍼(withTransaction) + 공통 에러 응답(handle, HttpError)
│   ├── migrate.js             서버 시작 시 migrations/의 SQL을 자동 적용
│   ├── rateLimit.js           요청 횟수 제한(limiter) 생성
│   └── token.js               JWT 발급/검증
├── migrations/
│   ├── 001_idle_progression.sql  업그레이드·자동화·환생 포인트 컬럼 추가
│   ├── 002_auto_open_time_and_prestige_shop.sql  자동 개봉 시간·환생 상점 컬럼 추가
│   ├── 003_golden_box_and_achievements.sql  황금 상자·수입 2배·누적 기록·업적 컬럼 추가
│   ├── 004_item_locks.sql  아이템 잠금 컬럼 추가
│   └── 005_ranking_season.sql  랭킹 시즌 컬럼 추가 (기존 기록은 시즌 1)
├── middleware/
│   └── auth.js                로그인 토큰(JWT) 검증
└── public/
    ├── index.html              프론트엔드 화면 구조 (HTML)
    ├── style.css               스타일
    └── app.js                  화면 동작 스크립트

구성요소								|  실행위치		|	역할
server.js, routes/, middleware/, db.js	|	Render	|	항상 켜져있는 백엔드 서버
public/index.html						|	Vercel	|	사용자가 보는 화면 (정적 파일)
실제 데이터(회원, 보물 기록)				|	Neon	|	클라우드 PostgreSQL 데이터베이스
코드 원본								|	GitHub	|	Render/Vercel이 여기서 코드를 가져감

DB 쿼리 입력 Neon 콘솔의 SQL Editor에서 
https://console.neon.tech 접속 후 로그인
프로젝트 클릭
왼쪽 메뉴에서 "SQL Editor" 클릭
쿼리 입력창에 SQL을 쓰고 Run
